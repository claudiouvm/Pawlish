# Pawlish

Improve, shorten, summarize, fix or translate any text you select on your Mac, with your own AI key.

**[pawlish.app](https://pawlish.app)** · [Download the latest version](https://github.com/claudiouvm/Pawlish/releases/latest) · [Report a problem](https://github.com/claudiouvm/Pawlish/issues)

This repository holds Pawlish's downloads, its update feed and its issue tracker. The app's source code is private.

## What it does

Select text in any app and a small bar appears next to it: improve, shorten, summarize, fix spelling or translate. You can
also use the ⌃⌥T shortcut. The result opens in a window you can copy from.

Pawlish works with your own key for OpenAI-compatible services or Anthropic, or with a model running on your Mac.

## Install

1. Download the DMG from [the latest release](https://github.com/claudiouvm/Pawlish/releases/latest) and drag Pawlish to
   Applications. It needs a Mac with Apple silicon and macOS 13 or later.
2. Pawlish isn't notarized by Apple yet. The first time, open it from System Settings → Privacy & Security → **Open
   Anyway**.
3. Allow the Accessibility permission when Pawlish asks: it needs it to read the text you select.

Updates download on their own, and each one is checked against a signature before it's installed.

## Price

## Privacy

The text you select goes straight to the AI service you chose, and nowhere else. Pawlish has no servers of its own.
Besides that, it checks this repository for updates, checks your license with Polar (the store that sells it) and sends
anonymous error reports that never include your text. The details are in the
[privacy notice](https://pawlish.app/privacy/).
